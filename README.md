Golden Hour: Twelve Rings — fly the Kestrel through twelve numbered rings over a sunset archipelago, mind your fuel, and bring her home to the runway. Three modes (Ring Course, Time Trial, Landing Challenge), throttle/pitch/roll/rudder flight with stall and fuel discipline, a lit HUD with altitude, speed, heading, fuel, rings, score and timer, and WebAudio-synthesised engine, wind, ring and crash sounds. Plays offline in desktop Chrome from static files.

## Run it

```sh
node serve.ts
```
